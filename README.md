# 🔐 Cyber Attack Detection System

A machine learning-based system designed to detect potential cyber attacks on web applications by analyzing URL patterns and behavioral features.

This project applies advanced techniques like graph-based segmentation and sequence alignment to identify malicious activity.

---

## 📌 Features

- Detects potential cyber attacks from input URLs  
- Uses pattern analysis and similarity matching  
- Implements graph-based segmentation for feature extraction  
- Applies dynamic programming techniques for comparison  
- Uses Needleman-Wunsch algorithm for dissimilarity scoring  
- Classifies URLs as safe or potentially malicious  
- Scalable architecture for real-world applications  

---

## 🧠 Core Concepts Used

- Graph-Based Segmentation  
- Dynamic Programming  
- Needleman-Wunsch Dissimilarity  
- Machine Learning for Classification  
- Pattern Recognition  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Backend:** Django
- **Libraries:** NumPy, Pandas, Scikit-learn    
- **Tools:** VS Code, Git  

---

## ⚙️ How It Works

1. Input URL is taken from user  
2. URL is segmented using graph-based techniques  
3. Extracted features are processed  
4. Needleman-Wunsch algorithm calculates similarity/dissimilarity  
5. Model evaluates the pattern  
6. Output is classified as **Safe** or **Malicious**
